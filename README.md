# Responsive Resume

A simple and responsive resume website built using **HTML** and **CSS**. This project is designed to display a professional resume with a clean layout and print-friendly styling.

## Features

- Responsive design
- Clean and modern layout
- Print-friendly (A4 size)
- HTML and CSS only
- Easy to customize

## Technologies Used

- HTML5
- CSS3

## Project Structure

```
Responsive-Resume/
│── index.html
│── style.css
└── README.md
```

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/YourUsername/YourRepository.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
